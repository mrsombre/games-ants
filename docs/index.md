# Документация games-ants

- [Концепция игры](./plan.md) - механики муравейника и границы первого прототипа.
- [Сравнение движков](./engine-comparison.md) - предварительный выбор 2D-движка и ограничения одного HTML.
- [Разработка](./development.md) - локальный запуск, архитектура, проверки и сборка.

## Правила

- Документация пишется на русском; команды и названия технологий сохраняются на английском.
- Используется OKF 0.2: у документа есть YAML frontmatter с обязательным `type`;
  рекомендуются `title`, `description` и `tags`. У индекса - `okf_version: "0.2"`.
- Добавляя документ, обновлять индекс его раздела. Ссылки внутри репозитория делать относительными.
- Планы реализации хранятся в `specs/plans/` в свободном формате. `docs/plan.md` хранит концепцию
  будущего продукта, а не шаги текущей реализации.
