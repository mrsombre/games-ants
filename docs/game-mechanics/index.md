# Игровые механики

Этот раздел описывает реализованные правила игры с точки зрения игрока. Детали модулей,
типов и алгоритмов находятся в разделе [«Проектирование системы»](../system-design/index.md).

- [Игровой экран и строительство](./construction.md) — устройство колонии, размещение
  чертежей, строительство, снос, выведение и роли муравьёв.
- [Задания и яйца](./tasks-and-eggs.md) — автоматическое назначение работы, кладки,
  хранение, стоимость выведения и прерывание заданий.

закрытой вкладки не учитывается.
