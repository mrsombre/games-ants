# Идеи развития

Этот раздел собирает предложения для будущих версий игры. Описанные механики пока
не реализованы; численные параметры — гипотезы для проверки в прототипах и пробных
партиях. Сохранение идеи в этом разделе не означает принятия решения о её реализации.

Целевой формат — отдельные партии продолжительностью 30–60 минут. Основные ориентиры:
Dota, Dungeon Keeper и RimWorld.

- [Глубина механик и баланс партии](./gameplay-and-balance.md) — роение как цель победы,
  специализация комнат, кормовые территории, феромоны, бой, события и адаптации колонии.

Текущие правила описаны в разделе [«Игровые механики»](../game-mechanics/index.md),
устройство движка — в разделе [«Проектирование системы»](../system-design/index.md).
Конкретные планы реализации хранятся отдельно в `specs/plans/`.
