# План игры про муравьёв

Статус: предварительная концепция, записана 5 сентября 2026 года. Минимальный технический каркас уже создан: React + Vite frontend и Hono Worker с единым локальным запуском. Каркас опубликован: [production](https://games-ants.warmvibes.workers.dev/). Локально реализован первый экран на PixiJS: лес, подземная сетка, строительство по чертежам, автономные муравьи и добыча еды. Состояние хранится только в памяти. Игровая версия ещё не опубликована.

## Концепция

Браузерная игра про управление муравейником, вдохновлённая механиками Fallout Shelter: строительство комнат, развитие поселения и экспедиции за полезными находками. Собственная тема, персонажи и оформление про муравьёв.

Игрок — ребёнок восьми лет. Основное устройство — компьютер, управление мышью.

Муравейник показан сбоку в разрезе и расширяется вниз. Игрок строит комнаты и отправляет муравьёв в рейды. Внутри муравейника муравьи действуют автономно. Матка остаётся на постоянном месте.

## Основные механики

- **Строительство:** добавление комнат по мере развития муравейника, преимущественно вниз. В первой версии доступны коридоры размером в одну клетку и комнаты шириной до четырёх клеток с горизонтальным расширением. Коридоры продолжаются только от коридоров, строительство бесплатное.
- **Автономная колония:** муравьи самостоятельно перемещаются и выполняют работу. Свободные исполнители получают задачи через общий аукцион: строительство важнее переноса яиц, среди подходящих муравьёв выбирается самый быстрый по времени пути. Коридор требует 20 рабочих секунд, клетка комнаты — 30; несколько рабочих ускоряют работу линейно.
- **Рейды:** в текущей версии разведчики уходят автоматически, отсутствуют за картой 5–60 секунд и приносят к матке 1–3 еды. Ручная отправка и риски оставлены на будущее.
- **Матка:** неподвижный центральный персонаж колонии. Каждые 30 секунд откладывает кладку в свободную соседнюю клетку комнаты; без места таймер стоит. Рабочие относят яйца в дальние свободные клетки. Вылупление и условия поражения пока не реализованы.
- **Виды муравьёв:** рабочие, разведчики и воины. Они отличаются цветом, размером и деталями. Воины пока патрулируют лес. Найм у матки стоит соответственно 1, 2 и 3 еды.

Предлагаемый игровой цикл: построить комнату → колония осваивает её → отправить рейд → получить полезные находки → расширить муравейник. Это рабочая гипотеза для первого прототипа.

## Первый прототип

Минимальный объём для проверки основного игрового цикла:

- Одна сцена муравейника в разрезе с возможностью строить вниз.
- Матка на постоянном месте и несколько автономных муравьёв.
- Три первоначальных вида: рабочие, разведчики и воины, с простыми визуальными отличиями.
- Универсальные комнаты и один ресурс — еда.
- Автономные вылазки разведчиков, возвращение и доставка еды.
- Простой UI: несколько счётчиков численности муравьёв и ресурсов, минимальные действия для строительства и рейдов.
- Сохранение прогресса отложено: перезагрузка начинает игру заново.

Критерий проверки: ребёнок может построить комнату, увидеть самостоятельную жизнь колонии, дождаться возвращения разведчика и использовать полученную награду для дальнейшего развития.

## Технический план

- Браузерный 2D-проект; нативное приложение сейчас не планируется.
- **pnpm** для инициализации проекта, зависимостей и команд разработки.
- Выбранный стек: **TypeScript + PixiJS + React + Vite**. PixiJS рисует игровую сцену, React отвечает за интерфейс. Обоснование — в [сравнении движков](./engine-comparison.md).
- Модель колонии и её сохранение отделить от отрисовки, чтобы автономное поведение и рейды можно было проверять независимо от графики.
- **Текущий прототип:** состояние только в памяти, без сохранений, миграций и обратной совместимости. Модель и стартовую базу свободно переписываем по мере развития. Сохранения из концепции отложены.
- **Cloudflare Workers** — планируемая площадка публикации браузерной сборки. Серверная игровая логика для первого прототипа пока не требуется.
- Сохранить первоначальное пожелание: отдельная автономная сборка в **один HTML со встроенными ресурсами**, запускаемая без веб-сервера. Для неё предусмотреть экспорт и импорт сохранения, поскольку поведение localStorage на `file://` не гарантировано. Ограничения и источники записаны в [сравнении движков](./engine-comparison.md).

## Порядок следующих шагов

1. **Выполнено:** определить первые роли, найм за еду, длительность разведки и строительства.
2. **Выполнено:** подключить PixiJS и первый экран строительства.
3. **Выполнено:** инициализировать проект через pnpm и настроить сборку frontend и Worker. PixiJS подключён следующим шагом.
4. **Выполнено локально:** минимальный игровой цикл. Сохранения отложены.
5. **Управление проверено в браузере:** чертежи, строительство и найм. Проверка понятности ребёнком — следующий шаг.
6. **Каркас опубликован** в Cloudflare Workers. Публикация игровой версии и проверка автономного HTML остаются следующими шагами.

Этот документ фиксирует концепцию будущей игры. Опубликован технический каркас. Локальная версия строительства описана в [руководстве первого экрана](./construction.md). Автономная колония и вылазки разведчиков реализованы локально; автономный HTML остаётся в планах.
