# Разбор мутаций

Проверено 6 сентября 2026 года. В прогоне 15 файлов логики движка и 135 тестов frontend.
Отдельный общий прогон включает ещё три HTTP-теста backend. Охват, команды и решения
по удалению слабых тестов описаны в [тестовом аудите](./testing.md).

| --- | ---: |
| Killed — отклонены тестами | 1465 |
| Timeout — обнаружены по лимиту времени | 31 |
| Survived — тесты не отличили | 44 |
| NoCoverage — участок не исполнен | 3 |

Исходный показатель Stryker — **96,95%**, порог команды — **95%**. Показатель не
пересчитан после ручной классификации. Формального результата 100% нет: оставшиеся
варианты перечислены полностью ниже. Среди них есть непроверяемая стоимость вычислений,
диагностические тексты и различия точно на границе численного допуска; они не объявлены
безусловно эквивалентными программами.

## Что обнаружила ревизия

Исправлены ожидания и добавлены сценарии, отличающие нарушение исключительности предметов
и мест хранения, кражу чужого заказа, повторное использование ID, выбор неподходящей роли,
проход через вертикальную стену, пропуск боя при движении и неправильные остатки времени.
Проверка резервов теперь утверждает результат первого аукциона: повторные торги раньше
скрывали ошибочную выдачу только одного задания. Проверка равной стоимости различает
неверный компаратор ID, а проверка точного прибытия — задержку логической клетки на шаг.

Прежний тест предполагаемого обхода через чертежи не содержал такого пути: карта сценария
исправлена. Слишком широкий стандартный toBeCloseTo заменён явной точностью там, где он
пропускал дополнительный шаг строительства. Тесты констант подсказок и повторные сценарии
удалены; правила новой модели проверяются через команды и наблюдаемое состояние.

## Все оставшиеся варианты

ID относятся к этому прогону и изменятся при изменении исходников. NC означает NoCoverage.
Пути строк в таблице отсчитываются от apps/frontend/src/game/. Предусловие «допустимый мир»
означает состояние, полученное из createGame через команды и stepGame; произвольная запись
во внутренние поля Game этим предусловием не разрешена.

## Артефакты

Полные замены кода, покрывающие тесты и статусы находятся в .tmp/mutation/report.json;
интерактивная версия — .tmp/mutation/report.html. Они создаются командой pnpm test:mutation
и не хранятся в Git. Конфигурация сохраняет все виды мутаций; общих исключений для строк,
сравнений или защитных условий нет. Корневая .tmp не копируется во временный проект.
